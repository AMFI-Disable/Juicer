Welcome to **Juicer V1.1.1**! Introducing Juicer Store Studio preflight package adoption, Homebrew lock auto-fixer, and external application auto-discovery.

## What's New in V1.1.1

### 1. Juicer Store Studio Package Adoption 🛒
* **1-Click Adoption of Standalone Apps**: Convert manually installed applications (from DMGs, ZIPs, or web browsers) into Homebrew Casks (`brew install --cask --adopt`) without losing user configuration.
* **Preflight Binary Verification**: Preflight check binary artifacts before adopt execution to prevent Homebrew from deleting existing apps during failed rollbacks.
* **Fallback Replace Mode**: One-click "Replace with Homebrew" (`--force`) fallback mode for corrupted apps.

### 2. Lock Auto-Fixer & All-App Discovery 🔧
* **Homebrew Locks Auto-Fixer**: Automatically detect and purge stale Homebrew lock files (`cask/.lock`, `formula/.lock`) that stall package operations.
* **Complete Application Discovery**: Auto-detect all macOS applications installed at `/Applications` and `~/Applications`, regardless of whether a Homebrew cask formula exists.

## Installation & Opening Instructions ⚠️

Because Juicer is locally compiled and not notarized, macOS Gatekeeper may show a *"damaged and can't be opened"* warning when downloading the zip file. 

To run Juicer:

1. **Via Homebrew Cask (Recommended)**:
   ```bash
   brew upgrade --cask juicer
   ```
2. **Via Direct Zip Download**:
   - Extract `Juicer-V1.1.1.zip` directly to `/Applications/Juicer.app`.
   - Clear Gatekeeper quarantine tag:
     ```bash
     xattr -cr /Applications/Juicer.app
     ```
   - Launch `Juicer.app` normally from Applications or Launchpad.
