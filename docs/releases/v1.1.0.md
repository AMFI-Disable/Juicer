Welcome to **Juicer V1.1.0**! Introducing the Global Command Palette, SDK Version Manager, Better Cmd-Tab Window Switcher, and System Extension Inspector.

## What's New in V1.1.0

### 1. Global Command Palette & SDK Version Manager 🎛️
* **Global Command Palette (`Cmd+Shift+K`)**: Instant search overlay across all 40+ Juicer tools, commands, and settings for rapid navigation.
* **SDK Version Manager**: Easily inspect and switch active system versions of Node.js (`nvm`), Python (`pyenv`), Ruby (`rbenv`), Rust (`rustup`), and Homebrew links.

### 2. Window Switcher & Extension Diagnostics 🪟
* **Better Cmd-Tab Window Switcher**: Enhanced application and window switcher with live window preview thumbnails, search filtering, and window closing.
* **System Extension Inspector**: Inspect loaded macOS DriverKit system extensions and legacy kernel extensions.

## Installation & Opening Instructions ⚠️

Because Juicer is locally compiled and not notarized, macOS Gatekeeper may show a *"damaged and can't be opened"* warning when downloading the zip file.

To run Juicer:

1. **Via Homebrew Cask (Recommended)**:
   ```bash
   brew upgrade --cask juicer
   ```
2. **Via Direct Zip Download**:
   - Extract `Juicer-V1.1.0.zip` directly to `/Applications/Juicer.app`.
   - Clear Gatekeeper quarantine tag:
     ```bash
     xattr -cr /Applications/Juicer.app
     ```
   - Launch `Juicer.app` normally from Applications or Launchpad.
