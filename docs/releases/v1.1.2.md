Welcome to **Juicer V1.1.2**! A major upgrade to Juicer Store Studio integrating core features inspired by CaskHub.

## What's New In V1.1.2

### 1. Native Password Authorization & Analytics Charts 📊
* **Native Sudo Password Dialog (`SUDO_ASKPASS`)**: Automatically triggers a native macOS GUI authentication prompt for `.pkg` installer casks requiring administrative access.
* **Top Charts & Popularity Shelf**: Live 30-day, 90-day, and 1-year Homebrew cask popularity rankings with exact install counts and gold/orange rank indicators.

### 2. Zombie Cask Repair & Mac App Store Safeguards 🧟
* **Zombie Cask Detection & 1-Click Repair**: Detects orphaned Homebrew receipts whose `.app` bundles were deleted on disk, with 1-click receipt cleanup or application reinstallation.
* **Mac App Store (MAS) Protection**: Automatically detects `_MASReceipt` inside app bundles to prevent destructive Homebrew overwrites or uninstalls.
* **Non-Blocking Download Size Lookup**: Asynchronous HTTP `HEAD` and byte-range requests to resolve cask download sizes (MB/GB) before downloading.

## Installation & Opening Instructions ⚠️

Because Juicer is locally compiled and not notarized, macOS Gatekeeper may show a *"damaged and can't be opened"* warning when downloading the zip file.

To run Juicer:

1. **Via Homebrew Cask (Recommended)**:
   ```bash
   brew upgrade --cask juicer
   ```
2. **Via Direct Zip Download**:
   - Extract `Juicer-V1.1.2.zip` directly to `/Applications/Juicer.app`.
   - Clear Gatekeeper quarantine tag:
     ```bash
     xattr -cr /Applications/Juicer.app
     ```
   - Launch `Juicer.app` normally from Applications or Launchpad.
