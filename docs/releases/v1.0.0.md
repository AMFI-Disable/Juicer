Welcome to **Juicer V1.0.0**! The foundational launch of the all-in-one native macOS developer suite and system utility.

## What's New In V1.0.0

### 1. Developer Cache Pruner & Storage Analyzer 🧹
* **Multi-Tool Cache Cleaner**: Deep clean Xcode DerivedData, CocoaPods, SwiftPM, npm, Yarn, Bun, Cargo, Docker, and Homebrew caches.
* **Disk Space Analyzer**: Interactive visual breakdown of disk usage by folder, file type, and application size.

### 2. Native App Uninstaller & System Tweaks 🚀
* **Deep Application Uninstaller**: Locate and clean hidden preference files, application support containers, caches, and launch agents.
* **macOS System Tweaks**: Toggle Dock animation speeds, Finder hidden files, screenshot save locations, and system responsiveness settings.

### 3. Real-Time Network & System Monitoring ⚡
* **Port & Process Inspector**: View active listening ports (Node, Python, Postgres, Redis) with 1-click process termination.
* **System Status Bar**: Live CPU, memory, and disk usage monitors in the macOS menu bar.

## Installation & Opening Instructions ⚠️

Because Juicer is locally compiled and not notarized, macOS Gatekeeper may show a *"damaged and can't be opened"* warning when downloading the zip file.

To run Juicer:

1. **Via Homebrew Cask (Recommended)**:
   ```bash
   brew install --cask AMFI-Disable/juicer/juicer
   ```
2. **Via Direct Zip Download**:
   - Extract `Juicer-V1.0.0.zip` directly to `/Applications/Juicer.app`.
   - Clear Gatekeeper quarantine tag:
     ```bash
     xattr -cr /Applications/Juicer.app
     ```
   - Launch `Juicer.app` normally from Applications or Launchpad.
